# Security Policy

## Reporting Security Vulnerabilities

The **Bangletv** team takes the security of our software products, streaming systems, and repository infrastructure seriously. If you believe you have found a security vulnerability, please report it to us as outlined below.

> **Important**: Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions. Instead, all security issues should be disclosed privately.

## Reporting a Vulnerability

If you discover a security vulnerability, please open a private draft security advisory directly via our GitHub repository:

1. Navigate to the **Security** tab of the `bangletv` repository on GitHub.
2. Under *Reporting*, click on **Advisories** and then **New draft advisory**.
3. Fill in the advisory details:
   - **Title**: A clear, descriptive summary of the vulnerability.
   - **Summary**: Impact and severity assessment.
   - **Details**: Comprehensive description, including pointers to vulnerable source code.
   - **Proof of Concept (PoC)**: Step-by-step instructions or configuration details to reproduce the issue safely.

Once submitted, our **Chief Advisor & Governance (Tareq Anwar Khan)**, along with the **Executive Editor & CNE** and the **Chief News Editor & Broadcasting Authority**, will review the report, verify the findings, and coordinate remediation efforts promptly.
